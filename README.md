>
> Некоторые антивирусы считают файлы WinDivert потенциально опасными или относят их к хакерским инструментам. В результате файл удаляется и отправляется в карантин. Обычно такое обнаружение называется `WinDivert` или `Not-a-virus:RiskTool.Multi.WinDivert`
>
> Добавьте каталог zapret в исключения антивируса либо отключите обнаружение PUA (потенциально нежелательных приложений). Например, в Kaspersky есть параметр "Обнаруживать легальные приложения, которые злоумышленники часто используют для нанесения вреда". Если вы уверенно понимаете настройки исключений, лучше добавить исключение; в противном случае рекомендуется отключить обнаружение PUA.

## ⚙️Использование

1. Сначала включите безопасный DNS (Secure DNS)
    * В Chrome активируйте "Использовать безопасный DNS" и укажите поставщика услуг, отличный от "Поставщик по умолчанию"
    * В Firefox включите "DNS через HTTPS", выберите режим "Персональный", затем "Выбрать провайдера/поставщика" и вручную укажите URL. Например, `https://dns.google/dns-query`, поскольку Cloudflare может быть заблокирован
    * Windows 11 позволяет включить Secure DNS непосредственно в параметрах ОС. [Инструкция находится здесь](https://remontka.pro/dns-over-https-windows-11/); для Windows 11 этот вариант рекомендуется
    * Владельцам роутеров Keenetic нужно включить параметр "Транзит запросов" в настройках роутера. Если его отключить, Secure DNS на компьютере может работать некорректно

2. Скачайте zip- или rar-архив с [последнего релиза](https://github.com/Centerkruchill/zapret-discord-youtube/releases/latest)

3. Откройте свойства загруженного архива и установите флажок "Разблокировать". Для архивов, открытых через 7-Zip или PeaZip, этот шаг не требуется

4. Распакуйте архив в каталог, путь к которому не содержит кириллицу и специальные символы

5. Запустите подходящий файл
    * Для поиска рабочей стратегии откройте **`service.bat`** -> `Run Tests` -> `Standard tests` -> `All configs`
    * Чтобы включить автозапуск, выберите **`service.bat`** -> `Install Service` -> *нужную стратегию*

## ℹ️Краткие описания файлов

- [**`general.bat ...`**](./general.bat) - ручной запуск стратегии

  Такой запуск удобен для проверки разных вариантов. Результат зависит от множества условий, поэтому **перебирайте стратегии (ALT, FAKE и другие), пока не найдёте подходящую**

- [**`service.bat`**](./service.bat) - установка автозапуска и дополнительные операции:
  - <ins>**`Install Service`** - добавляет выбранную стратегию в автозапуск через services.msc</ins>
  - **`Remove Services`** - удаляет стратегию и WinDivert из служб
  - **`Check Status`** - показывает состояние обхода и служб: стратегии в автозапуске и WinDivert
  - **`Game Filter`** - меняет режим обхода для игр и других сервисов, работающих с UDP и TCP-портами выше 1023.  
  **После изменения режима стратегию необходимо перезапустить.**  
  В скобках отображается текущее состояние: включено или выключено.
  - **`IPSet Filter`** - переключает обработку сервисов из `ipset-all.txt`.  
  Это удобно при проверке ресурса, который без zapret работает, а с ним перестаёт открываться  
  Возможные состояния указаны в скобках:
    - `none` - IP-адреса не проверяются
    - `loaded` - адреса сверяются со списком
    - `any` - фильтр применяется к любому IP-адресу  
  - **`Auto-Update Check`** - включает или отключает автоматический поиск обновлений
  - **`Replace active fakes`** - заменяет текущий фейк на другой из каталога `bin`
  - **`Update IPSet List`** - загружает актуальный `ipset-all.txt` из репозитория
  - **`Update Hosts File`** - обновляет hosts <ins>**для восстановления веб-версии Telegram и подключения к голосовому чату Discord**</ins>
  - **`Check for Updates`** - вручную проверяет наличие обновлений
  - **`Run Diagnostics`** - ищет распространённые причины неисправности zapret.  
  В конце доступна очистка кэша <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=11 /> `Discord`; это может вернуть работоспособность, если Discord внезапно перестал открываться
  - **`Run Tests`** - запускает проверку стратегий:
    - `Standard tests` - тестирует сайты из `utils/targets.txt`
    - `DPI checkers` - проверяет DPI у разных провайдеров, включая Cloudflare и Amazon


## ☑️Распространенные вопросы и проблемы

### После запуска `general*` ничего не появляется

- При запуске стратегии отдельным bat-файлом, а не через service, должен запуститься winws.exe (обход). Его можно увидеть на панели задач.  
Если процесс не появился, обратитесь к [#522](https://github.com/Centerkruchill/zapret-discord-youtube/issues/522)

### Не удалось подобрать стратегию
- Запустите командную строку с правами администратора
- Выполните команды по очереди:

    `netsh winsock reset`
  
    `netsh int ip reset all`
  
    `netsh winhttp reset proxy`
  
    `ipconfig /flushdns`

- Перезагрузите компьютер

### Не открывается Telegram в браузере
Запустите **`service.bat`** и выберите **`Update hosts file`**. Если текущий hosts устарел, программа предложит обновить его вручную:  
  - Скопируйте весь текст из открытого блокнота
  - Откройте файл `hosts` в созданной папке через текстовый редактор, запущенный от имени администратора
  - Вставьте скопированный текст в конец `hosts` или замените аналогичные записи, если вы уже добавляли их раньше
  - Сохраните файл и снова проверьте подключение. Если результата нет, убедитесь, что изменения действительно сохранились.

#### Работа не гарантируется. Если способ не помог, используйте [Desktop-версию](https://github.com/telegramdesktop/tdesktop/releases) с [локальным прокси](https://github.com/Centerkruchill/tg-ws-proxy) или любым публичным прокси.

### Обход не запускается или перестал работать

> [!IMPORTANT]
> **Стратегии могут со временем терять работоспособность.**
> После периода нормальной работы конкретная стратегия может перестать действовать, если её обнаружат.
> В репозитории есть много вариантов обхода. Если ни один не подходит, создайте новую стратегию на основе существующей и измените её параметры.
> О параметрах стратегий читайте [в документации](https://github.com/bol-van/zapret/blob/master/docs/readme.md#nfqws).

- Убедитесь, что в `service.bat` -> `Run Diagnostics` нет ошибок

- Проверьте, добавлен ли адрес нужного ресурса в доменные или IP-списки

- Запустите другие варианты, включая **`ALT`** и **`FAKE`**

- Выполните полную переустановку по инструкции ниже

- Также см. [#765](https://github.com/Centerkruchill/zapret-discord-youtube/issues/765)

### Как полностью переустановить или обновить проект?
- Сохраните добавленные вами ресурсы и другие данные
- Перезагрузите устройство
- Откройте `service.bat` -> `Remove Services`
- Запустите `service.bat` -> `Run Diagnostics`; устраните найденные ошибки и в конце выберите Y
- Удалите старый каталог zapret
- Скачайте свежую версию [со страницы релизов](https://github.com/Centerkruchill/zapret-discord-youtube/releases) (`zapret-discord-youtube-...`)
- Нажмите правой кнопкой по архиву и откройте свойства. Если внизу справа есть флажок разблокировки, установите его, нажмите "Применить" и "ОК"
- Распакуйте архив в новый каталог в корне диска, без пробелов, специальных символов и кириллицы
- Запускайте разные `general`-скрипты и проверяйте доступность ресурсов. Если интернет-ресурсы не работают, закройте программу через значок замка на панели задач и выберите другую стратегию
- После выбора рабочей стратегии включите автозапуск: `service.bat` -> `Install Service` -> выберите нужную стратегию

### Игра или приложение не работает при включённом обходе

- Проверьте в service.bat, что `Game Filter` имеет значение **`disabled`**, а `IPSet Filter` - **`none`**. Иначе фильтрация может повлиять на неожиданные для вас ресурсы.

### Античит обнаруживает WinDivert

- Изучите инструкцию в репозитории https://github.com/bol-van/zapret-win-bundle/tree/master/windivert-hide

### Windows 7 требует цифровую подпись драйвера WinDivert

- В каталоге [`bin`](./bin) замените `WinDivert.dll` и `WinDivert64.sys` одноимёнными файлами из [zapret-win-bundle/win7](https://github.com/bol-van/zapret-win-bundle/tree/master/win7)

### После удаления через [**`service.bat`**](./service.bat) WinDivert всё ещё есть среди служб

1. Найдите имя службы командой в командной строке Windows (Win+R, `cmd`):

```cmd
driverquery | find "Divert"
```

2. Затем остановите и удалите службу:

```cmd
sc stop название_из_первого_шага

sc delete название_из_первого_шага
```

### Не открывается <img src="https://cdn-icons-png.flaticon.com/128/1384/1384060.png" height=18 /> YouTube

- Проверьте настройку [Secure DNS](#%EF%B8%8Fиспользование)
- Отключите блокировщик рекламы: известно, что YouTube начал активно с ними бороться.
- Переберите остальные стратегии, особенно если прежняя недавно перестала работать.
- Дополнительная информация есть в [#251](https://github.com/Centerkruchill/zapret-discord-youtube/discussions/251)

### Не открывается <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=18 /> Discord

- Убедитесь, что [Secure DNS](#%EF%B8%8Fиспользование) настроен
- Сначала желательно определить стратегию, на которой открывается YouTube, и запустить её
- В `service.bat` выберите `Run Diagnostics` и выполните очистку кэша Discord
- После очистки проверьте приложение Discord
- Откройте Discord в браузере по адресу https://discord.com/app. Если браузерная версия работает, можно пользоваться ею
- Если Discord не работает и в браузере, повторно проверьте все стратегии: YouTube и Discord могут работать на разных вариантах
- См. также [#252](https://github.com/Centerkruchill/zapret-discord-youtube/discussions/252)

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/5968/5968804.png" height=18 /> Telegram

- Воспользуйтесь [tg-ws-proxy](https://github.com/Centerkruchill/tg-ws-proxy)
- Либо подключите бесплатный MTProto-прокси из интернета

### Не запускаются игры

Игр много, поэтому проверить и исправить каждую из них невозможно.

Начните с универсальной последовательности:
- через `service.bat` обновите ipset и включите `Game Filter`
- если результата нет, дополнительно включите `ipset any`

Учтите: режим `ipset any` способен нарушить открытие многих сайтов. Не оставляйте его включённым постоянно. Определите IP-адреса, которые использует игра, и внесите их в `ipset-all.txt`

Если проблема сохраняется, создайте обсуждение в разделе [Discussions](https://github.com/Centerkruchill/zapret-discord-youtube/discussions), а не issue, и дождитесь помощи других игроков.

### Ответа на проблему здесь нет

- Опишите её [в разделе issues](https://github.com/Centerkruchill/zapret-discord-youtube/issues)

## 🗒️Добавление адресов прочих ресурсов

Новые адреса для обхода добавляются в следующие файлы:
- **`list-general-user.txt`** - домены; поддомены учитываются автоматически
- **`list-exclude-user.txt`** - домены-исключения, например когда IP-сеть есть в `ipset-all.txt`, но конкретный домен фильтровать не нужно
- **`ipset-all.txt`** - IP-адреса и подсети
- **`ipset-exclude-user.txt`** - исключения для IP-адресов и подсетей
  - Файлы **`*-user.txt`** создаются автоматически при первом запуске `zapret` или `service.bat`
