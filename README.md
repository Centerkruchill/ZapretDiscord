>
> Добавьте каталог с zapret в исключения антивируса или отключите обнаружение PUA (потенциально нежелательных приложений). Например, Kaspersky предлагает настройку "Обнаруживать легальные приложения, которые злоумышленники часто используют для нанесения вреда". Исключение лучше настроить внимательно; если вы не уверены в своих действиях, рекомендуется отключить обнаружение PUA.

## ⚙️Установка и запуск

1. Сначала включите безопасный DNS (Secure DNS)
    * В Chrome включите "Использовать безопасный DNS" и выберите DNS-поставщика, отличного от "Поставщик по умолчанию"
    * В Firefox откройте "DNS через HTTPS", выберите режим "Персональный", затем "Выбрать провайдера/поставщика" и вручную укажите URL. Например, `https://dns.google/dns-query` (провайдер Cloudflare может оказаться заблокирован)
    * Windows 11 умеет включать Secure DNS непосредственно в настройках системы - [инструкция доступна здесь](https://remontka.pro/dns-over-https-windows-11/). Для пользователей Windows 11 это рекомендуемый способ
    * На роутерах Keenetic включите параметр "Транзит запросов". Если его отключить, Secure DNS на компьютере может работать некорректно

2. Загрузите zip/rar-архив со [страницы последнего релиза](https://github.com/Centerkruchill/zapret-discord-youtube/releases/latest)

3. Откройте свойства архива и установите флажок "Разблокировать". Пользователи 7-Zip и PeaZip могут пропустить этот шаг

4. Извлеките файлы в каталог, в пути к которому нет кириллицы и специальных символов

5. Откройте нужный файл
    * Для поиска рабочей стратегии: **`service.bat`** -> `Run Tests` -> `Standard tests` -> `All configs`
    * Для добавления в автозапуск: **`service.bat`** -> `Install Service` -> *выберите подходящую стратегию*

## ℹ️Назначение файлов

- [**`general.bat ...`**](./general.bat) - ручной запуск выбранной стратегии

  Такой запуск удобен для проверки стратегий. Результат зависит от множества условий, поэтому **перебирайте стратегии (ALT, FAKE и другие), пока не найдёте подходящую**

- [**`service.bat`**](./service.bat) - автозапуск и дополнительные операции:
  - <ins>**`Install Service`** - добавление выбранной стратегии в автозапуск (services.msc)</ins>
  - **`Remove Services`** - удаление стратегии и WinDivert из списка служб
  - **`Check Status`** - просмотр состояния обхода и служб, включая автозапущенную стратегию и WinDivert
  - **`Game Filter`** - смена режима обхода для игр и других сервисов, использующих UDP и TCP-порты выше 1023.  
  **После изменения параметра стратегию нужно запустить заново.**  
  В скобках отображается текущее состояние: включено или выключено.
  - **`IPSet Filter`** - настройка режима обхода для сервисов из `ipset-all.txt`.  
  Этот пункт полезен при проверке ресурса, который без zapret открывается, а с ним перестаёт работать  
  В скобках указывается состояние:
    - `none` - проверка не применяется ни к одному IP
    - `loaded` - IP сопоставляются со списком
    - `any` - фильтр применяется к любому IP  
  - **`Auto-Update Check`** - включение или отключение автоматической проверки обновлений
  - **`Replace active fakes`** - замена текущего фейка на другой файл из каталога `bin`
  - **`Update IPSet List`** - загрузка актуального `ipset-all.txt` из репозитория
  - **`Update Hosts File`** - обновление hosts <ins>**для восстановления веб-версии Telegram и подключения к голосовому чату Discord**</ins>
  - **`Check for Updates`** - ручной поиск новых версий
  - **`Run Diagnostics`** - проверка распространённых причин, из-за которых zapret может не запускаться или не работать.  
  В конце процедуры доступна очистка кэша <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=11 /> `Discord`, что иногда возвращает работоспособность приложения
  - **`Run Tests`** - запуск проверки стратегий:
    - `Standard tests` - тестирование сайтов из `utils/targets.txt`
    - `DPI checkers` - проверка DPI у разных провайдеров, включая Cloudflare и Amazon


## ☑️Частые вопросы и неисправности

### После запуска `general*` нет видимого результата

- При запуске стратегии отдельным bat-файлом, а не через service, должен появиться процесс winws.exe (обход), заметный на панели задач.  
Если процесса нет, обратитесь к [#522](https://github.com/Centerkruchill/zapret-discord-youtube/issues/522)

### Подходящей стратегии не нашлось
- Откройте командную строку с правами администратора
- По очереди выполните следующие команды:

    `netsh winsock reset`
  
    `netsh int ip reset all`
  
    `netsh winhttp reset proxy`
  
    `ipconfig /flushdns`

- Перезагрузите компьютер

### Не открывается Telegram в браузере
Запустите **`service.bat`** и выберите **`Update hosts file`**. Если используемый hosts устарел, программа предложит обновить его вручную:  
  - Выделите и скопируйте весь текст из открывшегося блокнота
  - Через текстовый редактор с правами администратора откройте файл `hosts` в созданной папке
  - Вставьте скопированное в конец `hosts` либо замените ранее добавленные аналогичные строки
  - Сохраните изменения и проверьте подключение. Если результата нет, убедитесь, что файл действительно сохранился.

#### Работоспособность не гарантируется. При отсутствии результата используйте [Desktop-версию](https://github.com/telegramdesktop/tdesktop/releases) с [локальным прокси](https://github.com/Centerkruchill/tg-ws-proxy) или любым публичным прокси.

### Обход не запускается или снова перестал работать

> [!IMPORTANT]
> **Стратегии не обязательно работают постоянно.**
> Найденная стратегия может некоторое время справляться с задачей, а затем перестать работать после её обнаружения.
> В репозитории есть несколько вариантов обхода. Если готовые варианты не подходят, создайте собственную стратегию на основе одной из них и измените её параметры.
> Описание параметров находится [здесь](https://github.com/bol-van/zapret/blob/master/docs/readme.md#nfqws).

- Убедитесь, что `service.bat` -> `Run Diagnostics` не показывает ошибок

- Проверьте наличие адреса ресурса в доменных или IP-списках

- Переберите другие стратегии, включая **`ALT`** и **`FAKE`**

- Выполните полную переустановку по инструкции ниже

- Дополнительные сведения есть в [#765](https://github.com/Centerkruchill/zapret-discord-youtube/issues/765)

### Как полностью обновить или переустановить проект?
- Сохраните добавленные вами ресурсы и настройки
- Перезагрузите устройство
- Выполните `service.bat` -> `Remove Services`
- Запустите `service.bat` -> `Run Diagnostics`; при наличии ошибок исправьте их и в конце подтвердите `Y`
- Удалите старый каталог zapret
- Возьмите свежую версию [со страницы релизов](https://github.com/Centerkruchill/zapret-discord-youtube/releases) (`zapret-discord-youtube-...`)
- Нажмите ПКМ по архиву и откройте свойства. Если внизу справа есть "Разблокировать", установите флажок, нажмите "Применить" и "ОК"
- Распакуйте архив в новый каталог в корне диска, без пробелов и специальных символов
- Запускайте разные скрипты `general` и проверяйте доступ к ресурсам; если доступ не восстановился, закройте программу через значок замка на панели задач и выберите другую стратегию
- После нахождения рабочего варианта добавьте его в автозапуск через `service.bat` -> `Install Service`

### Игра или приложение не работает при включённом обходе

- В `service.bat` проверьте, что `Game Filter` имеет состояние **`disabled`**, а `IPSet Filter` - **`none`**. Иначе фильтрация может затронуть неожиданные ресурсы.

### Античит обнаруживает WinDivert

- Инструкция по этому случаю находится здесь: https://github.com/bol-van/zapret-win-bundle/tree/master/windivert-hide

### Windows 7 требует цифровую подпись драйвера WinDivert

- В каталоге [`bin`](./bin) замените `WinDivert.dll` и `WinDivert64.sys` одноимёнными файлами из [zapret-win-bundle/win7](https://github.com/bol-van/zapret-win-bundle/tree/master/win7)

### После удаления через [**`service.bat`**](./service.bat) WinDivert остаётся среди служб

1. Узнайте имя службы, выполнив в командной строке Windows (Win+R, `cmd`):

```cmd
driverquery | find "Divert"
```

2. Затем остановите и удалите службу следующими командами:

```cmd
sc stop название_из_первого_шага

sc delete название_из_первого_шага
```

### Не открывается <img src="https://cdn-icons-png.flaticon.com/128/1384/1384060.png" height=18 /> YouTube

- Проверьте настройку [Secure DNS](#%EF%B8%8Fиспользование)
- Отключите блокировщик рекламы: известно, что YouTube начал активно с ними бороться.
- Повторно проверьте остальные стратегии, особенно если раньше всё работало.
- Смотрите также [#251](https://github.com/Centerkruchill/zapret-discord-youtube/discussions/251)

### Не запускается <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=18 /> Discord

- Убедитесь, что [Secure DNS](#%EF%B8%8Fиспользование) настроен
- Сначала желательно выяснить стратегию, на которой открывается сайт YouTube, и запустить её.
- Откройте `service.bat` -> `Run Diagnostics` и очистите там кэш Discord.
- Проверьте приложение Discord и определите, помогла ли очистка кэша.
- Откройте Discord в браузере: https://discord.com/app. Если веб-версия работает, временно используйте её.
- Когда Discord не работает и в браузере, снова проверьте все стратегии: YouTube и Discord могут работать на разных вариантах.
- Дополнительное обсуждение: [#252](https://github.com/Centerkruchill/zapret-discord-youtube/discussions/252)

### Не подключается <img src="https://cdn-icons-png.flaticon.com/128/5968/5968804.png" height=18 /> Telegram

- Воспользуйтесь [tg-ws-proxy](https://github.com/Centerkruchill/tg-ws-proxy)
- Другой вариант - бесплатные MTProto-прокси из интернета

### Игра не работает

Игр много, поэтому проверить и исправить каждую из них отдельно невозможно.

Начните с универсального варианта:
- через `service.bat` обновите ipset и включите `Game Filter`
- если это не помогло, дополнительно включите `ipset any`

Учтите, что режим `ipset any` может нарушить открытие многих сайтов. Не оставляйте его включённым постоянно: выясните IP-адреса, используемые игрой, и внесите их в `ipset-all.txt`

Если проблема сохранится, создайте обсуждение в разделе [Discussions](https://github.com/Centerkruchill/zapret-discord-youtube/discussions), а не issue, и дождитесь ответов других игроков.

### В списке нет моей проблемы

- Опишите её [здесь](https://github.com/Centerkruchill/zapret-discord-youtube/issues)

## 🗒️Добавление адресов других ресурсов

Расширить список адресов для обхода можно через следующие файлы:
- **`list-general-user.txt`** - домены; поддомены учитываются автоматически
- **`list-exclude-user.txt`** - домены, которые нужно исключить (например, когда сеть есть в `ipset-all.txt`, но конкретный домен фильтровать не требуется)
- **`ipset-all.txt`** - IP-адреса и подсети
- **`ipset-exclude-user.txt`** - IP-адреса и подсети, которые нужно исключить
  - Файлы **`*-user.txt`** создаются автоматически при первом запуске `zapret` либо `service.bat`
